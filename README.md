# CV y portafolio · Jesús Leonardo Martínez Rodrigues

Sitio estático, accesible y adaptable a móvil. HTML semántico, CSS y JavaScript sin dependencias de ejecución.

## Ejecutar

Servir la carpeta raíz con cualquier servidor HTTP estático. Por ejemplo, `python -m http.server 8080 `.

## Interacciones

- Filtros por área y búsqueda por proyecto o tecnología.
- Fichas de arquitectura en un diálogo nativo: cierre con Escape y gestión de foco del navegador.
- Diagrama interactivo de JARVIS.
- Tema claro/oscuro, respetando la preferencia del sistema.
- Contacto, copia de correo y descarga de PDF.
- Respeto de movimiento reducido, navegación por teclado y enlaces de salto.

## Contenido

`projects.json` contiene el catálogo técnico; `index.html` conserva el contenido legible sin JavaScript. `styles.css` define el sistema visual y la impresión. `app.js` implementa interacciones locales y no envía datos a un servidor.

No hay trackers, formularios de captura, cuentas ni backend. La información de formación y experiencia procede del titular. Los estados de proyectos distinguen capacidades y límites; no se publican métricas de dominio de lenguajes ni experiencia laboral inventadas.
